API Documentation

REST API endpoints for the SwachhLens backend. Base URL: /api

Authentication

All protected endpoints require a JWT token in the Authorization: Bearer <token> header.

POST/api/auth/register
Register a new user account.
Body: { name, email, password, role: "citizen"|"employee" }
Returns: 201 Created
POST/api/auth/login
Log in and receive a JWT token.
Body: { email, password }
Returns: { access_token, token_type, user: { id, name, email, role } }
POST/api/auth/logout
Log out the current user.
Auth: Required
GET/api/auth/me
Get current user profile.
Auth: Required
Returns: { id, name, email, role }

Waste Reports

GET/api/reports
List all reports for the current user.
Auth: Required
GET/api/reports/stats
Get report statistics (resolved, active, on-time).
Auth: Required
POST/api/reports
Submit a new waste report with photo and location.
Auth: Required
Body: multipart/form-data { location, description, lat, lng, photo }
PATCH/api/reports/{report_id}/assign
Assign a report to a crew member (group lead only).
Auth: Required (group lead)
PATCH/api/reports/{report_id}/collect
Mark a report as collected by a crew member.
Auth: Required (employee)
PATCH/api/reports/{report_id}/verify
Verify a completed cleanup (group lead only).
Auth: Required (group lead)
PATCH/api/reports/{report_id}/cancel
Cancel a pending report (citizen only).
Auth: Required (citizen)
DELETE/api/reports/{report_id}
Permanently delete a report.
Auth: Required

AI Waste Analysis

POST/api/analyze
Upload a photo for AI waste classification and severity analysis.
Auth: Required
Body: multipart/form-data { photo }
Returns: { waste_type, severity, confidence, summary }

GIS & Bin Monitoring

GET/api/gis
Get bin locations and fill levels for the map view.
Auth: Required
PATCH/api/gis/bins/{bin_id}
Update a bin's fill level or status.
Auth: Required (employee)

Community

GET/api/community/leaderboard
Get the community leaderboard ranked by verified reports and points.
Auth: Required

Admin Tasks

POST/api/admin/login
Admin/Employee login with agency-issued credentials.
Body: { email, password }
GET/api/admin/tasks
Get all tasks for the admin view.
Auth: Required (admin/employee)
POST/api/admin/tasks
Create a new task manually.
Auth: Required (admin)
GET/api/admin/employees
List all employees for assignment purposes.
Auth: Required (admin/lead)
GET/api/admin/reports
Get all reports for admin oversight.
Auth: Required (admin)
GET/api/admin/employee-tasks
Get tasks assigned to the current employee.
Auth: Required (employee)

Constants

GET/api/constants
Get platform constants (waste types, statuses, severity levels).
Auth: Not required

Notes

  • All endpoints return JSON responses.
  • Protected endpoints require Authorization: Bearer <jwt_token> header.
  • The API uses a FastAPI backend with SQLite database.
  • Photo uploads use multipart/form-data encoding.
  • Error responses include a detail field with the error message.
